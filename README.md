

# 来客数予測シミュレーター & アンケートシステム

このプロジェクトは、「店舗の来客数予測」に関する研究を紹介するWebアプリケーションです。  
過去のデータ（天気、曜日、イベント等）に基づき未来の来客数を予測し、その予測に対する信頼性や要因を提示することで、店舗運営の効率化（スタッフ配置、商品準備など）を目指します。

このアプリケーションでは、ベイズ統計的手法を用いた来客数予測のシミュレーションと、そのシステムに関する需要を調査するためのアンケート機能を提供します。

##  主な機能

1.  **来客数予測シミュレーター (`/`)**

      * 特定の日付と条件（プロモーション、休日など）を指定して、来客数を予測します。
      * 予測結果は、予測の中央値と94%信用区間（結果が94%の確率で収まる範囲）で表示されます。
      * PyMCを利用した学習済みベイズモデル（`static/sales_model_trace.nc`）を用いて予測を実行します。

2.  **アンケートフォーム (`/survey`)**

      * 本予測システムの有用性や現場での利用に関する意見を収集するためのアンケート機能です。
      * 回答はCSVファイル（`data/result.csv`）に自動で保存されます。

3.  **アンケート結果の可視化 (`/results`)**

      * 収集したアンケート結果をグラフで可視化し、分析するためのダッシュボードです。
      * このページは管理者向けの機能であり、Basic認証によって保護されています。
      * **ID**: `admin`
      * **パスワード**: `password123`

##  技術スタック

  * **バックエンド**: Python, Flask
  * **予測モデル**: PyMC, ArviZ
  * **データ処理**: Pandas, NumPy
  * **可視化**: Matplotlib, Seaborn (バックエンドでグラフ生成)

### 特徴的な実装

  * **モデルの遅延読み込み**: アプリケーション起動時のメモリ負荷を軽減し、起動時間を短縮するため、予測モデルは最初の予測リクエスト時に一度だけ読み込まれるように設計されています。

## 🚀 セットアップと実行方法

### 1\. 前提条件

  * Python 3.8以上
  * 学習済みモデルファイル (`sales_model_trace.nc`) が `static/` ディレクトリに配置されていること。

### 2\. リポジトリのクローン

```bash
git clone <リポジトリのURL>
cd <リポジトリ名>
```

### 3\. 必要なライブラリのインストール

プロジェクトに必要なライブラリをインストールします。`requirements.txt`を作成し、以下の内容を記述してください。

**requirements.txt**

```
flask
pandas
numpy
pymc
arviz
pytensor
matplotlib
seaborn
```

その後、以下のコマンドを実行します。

```bash
pip install -r requirements.txt
```

### 4\. アプリケーションの実行

以下のコマンドで開発サーバーを起動します。

```bash
python app.py
```

サーバーが起動したら、Webブラウザで `http://127.0.0.1:5000` にアクセスしてください。

## 📝 注意事項

  * **予測モデル**: このアプリケーションは、事前に学習されたモデルファイル `static/sales_model_trace.nc` が存在することを前提としています。ファイルがない場合、予測機能は動作しません。
  * **認証情報**: 結果表示ページの認証情報（ID/パスワード）は `app.py` 内でハードコードされています。本番環境で利用する場合は、環境変数などを用いてより安全な方法で管理することを推奨します。
  * **デバッグモード**: 現在 `app.run(debug=True)` となっており、開発モードで実行されます。公開する際には `debug=False` に変更してください。
